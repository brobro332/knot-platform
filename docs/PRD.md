# Knot (낫) - 공동 목표 빌드 플랫폼 구체화 명세서

이 문서는 추상적인 개념을 넘어, 실제 개발에 즉시 착수할 수 있도록 **화면 구성(Pages), 유저 플로우(User Flow), 그리고 데이터베이스 스키마(DB Schema)**를 구체적으로 정의한 최종 기획 명세서입니다.

## User Review Required

> [!IMPORTANT]
> 타임라인에 '데이트 일정'과 '지출'이 합쳐지면서 앱의 일상적인 활용도가 훨씬 높아졌습니다! 이 명세서가 사용자님이 머릿속에 그리는 최종 그림과 일치한다면, 승인(진행)해 주시면 바로 프로젝트 생성과 코딩 작업을 시작하겠습니다.

---

## 1. 핵심 유저 플로우 (User Flow)

1. **가입 및 팀 생성**: 유저 A가 소셜 로그인(카카오/구글)으로 가입 -> '팀 생성' 클릭 -> 6자리 초대 코드 발급
2. **팀 합류**: 유저 B가 가입 -> '초대 코드 입력' -> 유저 A와 유저 B가 하나의 '팀(Team)'으로 묶임
3. **목표 설정**: 두 사람이 첫 번째 공동 목표 생성 (예: "우리의 첫 신혼집 자금 모으기", 타입: 금액, 목표치: 5000만원)
4. **타임라인 기록 (일상 사용)**: 
   - 큰 퀘스트(마일스톤) 추가 (예: "웨딩홀 투어")
   - 일상 데이트 일정 추가 (예: "이번 주말 홍대 데이트")
   - 지출 내역 태깅 (데이트나 퀘스트 완료 후 타임라인 노드에 지출액 기록)
5. **공동 게이지바 업데이트**: 카카오 모임통장 등에 입금할 때마다 앱의 총액(게이지바)을 갱신하며 함께 성취감을 느낌

## 2. 구체적인 화면(Page) 명세

### 2.1. `/login` (로그인 및 온보딩 페이지)
- **UI 요소**:
  - DATT 패밀리 계정 연동을 강조하는 소셜 로그인 버튼 (카카오, 구글)
  - 로그인 직후 소속된 팀이 없으면 [새 팀 만들기] / [초대 코드 입력하기] 버튼 노출

### 2.2. `/dashboard` (메인 대시보드 - 목표 한눈에 보기)
- **UI 요소**:
  - **최상단**: 팀 이름과 프로필 (예: "A ❤️ B")
  - **메인 전광판 (One-Team Gauge)**: 
    - 텍스트: "목표 달성까지 2,500,000원 남았어요!"
    - 비주얼: 화면 중앙을 꽉 채우는 원형 프로그레스 바(0~100%)
    - 액션 버튼: `[+ 모임통장 잔고 업데이트]` 버튼 (개별 기여도 입력 없이 총액만 덮어쓰기)

### 2.3. `/timeline` (우리의 기록 타임라인)
- **UI 요소**:
  - 세로로 길게 이어지는 예쁜 타임라인 선과 노드(Node)들
  - **[+ 노드 추가]** 버튼을 누르면 3가지 타입 중 선택 가능:
    1. **마일스톤(퀘스트)**: 굵직한 목표나 할 일
    2. **데이트 일정**: 소소한 만남 기록 (DATT 서비스와 엮을 수 있는 핵심 포인트)
    3. **지출 기록**: 해당 일정/데이트에서 발생한 비용을 적어 타임라인 위에 돈이 나간 흐름을 박제

### 2.4. `/quests` (세부 할 일 목록)
- **UI 요소**:
  - 타임라인 노드 하위에 달리는 세부 체크리스트 (예: 웨딩홀 투어 노드 아래에 A웨딩홀, B웨딩홀 체크박스)
  - 스와이프 액션으로 직관적인 완료 처리

## 3. 구체적인 데이터베이스 스키마 (Supabase)

실제 구축될 PostgreSQL 데이터베이스의 핵심 테이블과 컬럼 구조입니다.

### 3.1. `users`, `teams`, `team_members`
- 통합 계정 및 커플(팀) 연동을 위한 기본 테이블

### 3.2. `goals` (공동 목표)
- `id`, `team_id`, `title`, `goal_type`
- `target_value` (Integer): 목표 수치
- `current_value` (Integer): 현재 달성 수치 (모임통장 총액)

### 3.3. `timeline_events` (타임라인 노드 - 핵심 확장)
- `id` (UUID)
- `team_id` (UUID)
- `event_type` (Enum): `MILESTONE`(큰 퀘스트), `DATE`(데이트 일정), `EXPENSE`(지출)
- `title` (String): 이벤트 이름 (예: "홍대 데이트", "웨딩홀 계약금")
- `amount` (Integer, null 허용): 지출이 발생한 경우 금액 기록
- `event_date` (Date): 일정이 있는 날짜
- `is_completed` (Boolean): 완료 여부
