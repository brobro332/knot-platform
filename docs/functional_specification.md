# Knot (낫) 기능 정의서

| 대분류 | 중분류 | 기능명 | 상세 설명 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **계정/인증** | 회원가입/로그인 | 소셜 로그인 | 카카오, 구글 기반의 소셜 로그인 (DATT 통합 계정 SSO 연동) | P1 |
| | 팀 관리 | 팀 생성 및 초대 | 새로운 그룹(팀)을 생성하고 6자리 초대 코드 발급 | P1 |
| | | 팀 가입 | 발급받은 초대 코드를 입력하여 상대방의 팀에 합류 | P1 |
| **대시보드** | 공동 목표 관리 | 목표 설정 | 목표 타이틀, 타입(금액/퍼센트/횟수), 목표치(Target) 설정 | P1 |
| | | 진척도 업데이트 | 현재 모인 총액(또는 수치)을 수동으로 입력하여 갱신 (개별 기여도 분리 없음) | P1 |
| | | 원팀 시각화 | 목표 달성률을 프로그레스 바(One-Team Gauge) 및 축하 애니메이션으로 표시 | P1 |
| **타임라인** | 노드(Node) 관리 | 마일스톤 생성 | 타임라인 상에 굵직한 목표(예: 상견례, 집 계약) 노드 추가 | P1 |
| | | 데이트 일정 추가 | 일상적인 만남 및 데이트 스케줄 노드 추가 | P2 |
| | | 지출 내역 기록 | 특정 일정/마일스톤 노드에 발생한 비용 및 영수증 기록 | P2 |
| | 타임라인 뷰 | 로드맵 시각화 | 생성된 노드들을 순서대로 정렬하여 세로형 스크롤 UI로 렌더링 | P1 |
| **퀘스트** | 할 일 관리 | 체크리스트 추가 | 타임라인 노드 하위에 세부 할 일(Quest) 항목 생성 | P2 |
| | | 담당자 할당 | 할 일의 담당자를 명시 (본인, 파트너, 혹은 공동) | P2 |
| | | 완료 상태 토글 | 스와이프 등의 액션으로 할 일을 완료(Done) 상태로 전환 | P2 |
| **외부 연동** | DATT 시너지 | 장소 공유 동의(UGC) | 일정 기록 시 DATT 생태계(추천 장소)로의 데이터 공유 동의 체크 | P3 |
| | | 코스 추천 링크 | 데이트 일정 노드 클릭 시 DATT 앱으로 유도하는 추천 퀵 링크 제공 | P3 |
